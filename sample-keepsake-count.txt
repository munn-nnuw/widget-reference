【概要】
サンプル名：記念品カウンター
何をするか：拾った記念品の合計を表示し、次の返答へ引き継ぐ。
提供者の表示名：ウィジェット相談室
元の作品・投稿・配布ページ（公開URL、任意）：なし
対象の版（版番号・日付・固定リンクのいずれか）：0.1

【掲載・利用の希望】
索引への掲載（可／不可）：可
資料の転載・ミラー（可／不可／条件付き）：リンクによる紹介可
コードや本文の改変・再配布（可／不可／条件付き）：自分のPinxAI作品に合わせた改変・設置可。サンプル原稿の再配布は個別確認。
AIが回答時にサンプルを参照する利用（可／不可／条件付き）：可
適用するライセンス、条件、必要な表記があれば記載：上記の通り。モデルの訓練用途は対象外。

【設置】
表示する場面と位置：固定イントロの後、各AI返答の末尾
ウィジェット名／関数名：記念品カウンター／KeepsakeCount
常時有効の設定／トリガーキーワード：空いている作品でオン／設定なし
ウィジェット以外の変更・依存する既存設定（なければ「なし」）：なし
タグで受け取る値（意味・型。初期値と欠落時の扱いも必要に応じて）：count は確定した合計を示す0以上の整数。合計不明は count 属性を省略する。

【AI用プロンプト】
固定イントロ以外の各AI返答末尾に <KeepsakeCount count={0} /> の形のタグを一つだけコード枠外に出す。数値例は固定しない。新規チャットの開始時だけ0個を基準とする。以後は直近の確定した合計を継ぎ、今回の本文で新たな入手が成立した分だけ足す。申し出や予定、過去の入手の言及・引用で加算しない。直近タグが欠けても、確認できる過去の合計と以降の確定入手から復元する。合計が決められなければ <KeepsakeCount /> を出し、推測で0に戻さない。

【プレビュー用タグ】
<KeepsakeCount count={0} />

【コード】
function KeepsakeCount(props) {
  const count = props.count;
  const valid = Number.isSafeInteger(count) && count >= 0;

  return (
    <section style={{ padding: 12 }}>
      <strong>記念品</strong>
      <div>{valid ? count + '個' : '不明'}</div>
    </section>
  );
}

【再現・確認】
試す入力と操作：新規チャットで入手前→一つ入手→その入手を思い出すだけ、の順に進める。設定画面で count を省いたタグや負数のタグも試す。
期待する結果：0個→1個→1個。属性欠落や負数は「不明」。通常の会話だけで値は変わらない。
実際に確認した場所・日付・結果（未確認ならその旨）：PinxAI実機は未確認。
任意の補足（失敗例、対処、既知の制限、画像など）：返答間の引き継ぎ例。別チャットへの自動保存はない。
