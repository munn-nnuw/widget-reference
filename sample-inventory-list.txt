PinxAI ウィジェットサンプル投稿書式 v0.1

【概要】
サンプル名：所持品一覧
何をするか：受け取った品や個数を、確定した変化だけ反映して表示する。
提供者の表示名：ウィジェット相談室
元の作品・投稿・配布ページ（公開URL、任意）：なし
対象の版（版番号・日付・固定リンクのいずれか）：0.1

【掲載・利用の希望】
索引への掲載（可／不可）：可
資料の転載・ミラー（可／不可／条件付き）：リンクによる紹介可
コードや本文の改変・再配布（可／不可／条件付き）：自分のPinxAI作品に合わせた改変・設置可。サンプル原稿の再配布は個別確認。
AIが回答時にサンプルを参照する利用（可／不可／条件付き）：可
適用するライセンス、条件、必要な表記があれば記載：上記の通り。モデルの訓練用途は対象外。

【設置】
表示する場面と位置：固定イントロ後のAI返答末尾
ウィジェット名／関数名：所持品一覧／InventoryList
常時有効の設定／トリガーキーワード：空いている作品でオン／設定なし
ウィジェット以外の変更・依存する既存設定（なければ「なし」）：なし
タグで受け取る値（意味・型。初期値と欠落時の扱いも必要に応じて）：items は id、name、count を持つ品の配列。確定した空は []、不明は属性なし。

【AI用プロンプト】
固定イントロ以外の各AI返答末尾に <InventoryList items={[{id:"rope",name:"ロープ",count:1}]} /> の形のタグを一つコード枠外に出す。items は現に所持している全件。id は品を区別する固定の文字列、name は品名、count は1以上の整数。例を事実にしない。この見本の新規開始時は空、途中では直近の確定一覧を継ぐ。受け取り・使用・手放しが本文で成立した品の数だけ変え、0になった品は外す。候補・過去の言及は変更理由にしない。確定した空は items={[]}。引き継げず不明なら items 属性を省略する。

【プレビュー用タグ】
<InventoryList items={[{id:"rope",name:"ロープ",count:1}]} />

【コード】
function InventoryList({ items }) {
  const valid = Array.isArray(items) && items.every(item =>
    item && typeof item.id === 'string' && item.id.trim() &&
    typeof item.name === 'string' && item.name.trim() &&
    Number.isSafeInteger(item.count) && item.count > 0
  ) && new Set(items.map(item => item.id)).size === items.length;

  if (!valid) return <p>所持品は不明です。</p>;
  if (!items.length) return <p>所持品なし。</p>;

  return (
    <section aria-label="所持品">
      <ul>{items.map(item => <li key={item.id}>{item.name} × {item.count}</li>)}</ul>
    </section>
  );
}

【再現・確認】
試す入力と操作：新規開始の空一覧から品を一つ受け取る。その品に言及するだけの返答と、実際に使い切った返答を順に確認する。別途属性なしも試す。
期待する結果：なし → 1個 → 1個 → なし。属性がなければ不明。
実際に確認した場所・日付・結果（未確認ならその旨）：PinxAI実機は未確認。
任意の補足（失敗例、対処、既知の制限、画像など）：同名でも別個に管理したい品は別IDにする。携行・保管を区別するなら、確定済みの所在を別の値として追加する。
