【AI用プロンプト】
固定イントロ以外、人物の現在状態を表示する場面では、返答末尾に <CharacterStatus people={[{id:"a",name:"旅人",state:"休憩中"},{id:"b",name:"案内役",state:""}]} /> の形のタグを一つコード枠外に出す。表示対象は現在の同行者。id は同じ人物の固定文字列、name は表示名、state は本文で確定した現在状態か空文字。前回の確定一覧を継ぎ、今回の本文で同行・離脱・状態変化が成立した人物だけ更新する。一時の不在と同行終了を分ける。確定空は people={[]}、一覧不明は属性を省略。例の人物を追加しない。

【プレビュー用タグ】
<CharacterStatus people={[{id:"a",name:"旅人",state:"休憩中"},{id:"b",name:"案内役",state:""}]} />

【コード】
function CharacterStatus({ people }) {
  const valid = Array.isArray(people) && people.every(person =>
    person && typeof person.id === 'string' && person.id.trim() &&
    typeof person.name === 'string' && person.name.trim() && typeof person.state === 'string'
  ) && new Set(people.map(person => person.id)).size === people.length;

  if (!valid) return <p>同行者の一覧は不明です。</p>;
  if (!people.length) return <p>同行者なし。</p>;

  return (
    <dl>
      {people.map(person => (
        <div key={person.id}>
          <dt>{person.name}</dt>
          <dd>{person.state.trim() || '状態不明'}</dd>
        </div>
      ))}
    </dl>
  );
}

【再現・確認】
試す入力と操作：二人が同行している状態から片方だけ休憩を終える。もう片方は別室で待機させ、次に同行終了が明示された場面を試す。
期待する結果：変化した一人だけ更新。一時不在で一覧から落ちず、同行終了が確定した人物だけ外れる。
