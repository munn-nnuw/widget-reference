PinxAI ウィジェットサンプル投稿書式 v0.1

【概要】
サンプル名：日時・現在地カード
何をするか：本文で確定した日時と現在地を一枚のカードに表示する。
提供者の表示名：ウィジェット相談室
元の作品・投稿・配布ページ（公開URL、任意）：なし
対象の版（版番号・日付・固定リンクのいずれか）：0.1

【掲載・利用の希望】
索引への掲載（可／不可）：可
資料の転載・ミラー（可／不可／条件付き）：リンクによる紹介可
コードや本文の改変・再配布（可／不可／条件付き）：自分のPinxAI作品に合わせた改変・設置可。サンプル原稿の再配布は個別確認。
AIが回答時にサンプルを参照する利用（可／不可／条件付き）：可
適用するライセンス、条件、必要な表記があれば記載：上記の通り。モデルの訓練用途は対象外。

【設置】
表示する場面と位置：固定イントロ後のAI返答末尾
ウィジェット名／関数名：日時・現在地カード／SceneInfo
常時有効の設定／トリガーキーワード：空いている作品でオン／設定なし
ウィジェット以外の変更・依存する既存設定（なければ「なし」）：なし
タグで受け取る値（意味・型。初期値と欠落時の扱いも必要に応じて）：when と place は文字列。不明な項目は空文字。

【AI用プロンプト】
固定イントロ以外の各AI返答末尾に <SceneInfo when="1日目・朝" place="街の広場" /> の形のタグを一つ、コード枠外に出す。例の日時と場所は固定しない。when は本文で確定した作中の日時、place は主人公が実際にいる場所。時間経過と到着が確定したときだけ変更し、変化がない項目は直近の確定値を継ぐ。未確定の項目は空文字にする。

【プレビュー用タグ】
<SceneInfo when="1日目・朝" place="街の広場" />

【コード】
function SceneInfo({ when, place }) {
  const time = typeof when === 'string' ? when.trim() : '';
  const location = typeof place === 'string' ? place.trim() : '';

  return (
    <dl style={{ margin: 0, padding: 12, overflowWrap: 'anywhere' }}>
      <dt>日時</dt>
      <dd>{time || '不明'}</dd>
      <dt>現在地</dt>
      <dd>{location || '不明'}</dd>
    </dl>
  );
}

【再現・確認】
試す入力と操作：見本タグで表示を確認し、place を抜いたタグも試す。会話で行き先を提案しただけの返答と、実際に到着した返答を比べる。
期待する結果：到着までは元の場所。place が欠けたときは場所だけ不明。
実際に確認した場所・日付・結果（未確認ならその旨）：PinxAI実機は未確認。
任意の補足（失敗例、対処、既知の制限、画像など）：既存のINFOがあれば、出どころと残したい内容を確認する。これは汎用のINFO停止設定ではない。
