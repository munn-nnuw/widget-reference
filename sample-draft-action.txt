何をするか：「周囲を調べる」を押すとチャット入力欄へ追記する。
提供者の表示名：ウィジェット相談室
元の作品・投稿・配布ページ（公開URL、任意）：なし

【設置】
表示する場面と位置：固定イントロの後、探索場面で周囲を調べられるAI返答の末尾
ウィジェット名／関数名：行動の下書きボタン／DraftAction
常時有効の設定／トリガーキーワード：空いている作品でオン／設定なし

【AI用プロンプト】
固定イントロの後、探索中にプレイヤーが周囲を調べられる場面で、本文末尾に <DraftAction /> を一つだけコード枠外に出す。タグの出力やボタンの表示だけで行動は成立しない。実際に送信された最新の入力を受け、状況に合わせて行動を描く。過去入力や引用の行動文を再処理しない。

【プレビュー用タグ】
<DraftAction />

【コード】
function DraftAction() {
  const [status, setStatus] = useState('ready');

  async function addDraft() {
    setStatus('pending');
    try {
      const result = await pinx.chat.insertText('周囲を調べる');
      setStatus(result?.ok ? 'done' : 'error');
    } catch {
      setStatus('error');
    }
  }

  return (
    <section style={{ padding: 12 }}>
      <button type="button" onClick={addDraft} disabled={status === 'pending' || status === 'done'}>
        周囲を調べる
      </button>
      <div role="status">
        {status === 'done' && '下書きに入りました。確認して送信してください。'}
        {status === 'error' && '入力欄のあるプレビューチャットで試してください。'}
      </div>
    </section>
  );
}

【再現・確認】
試す入力と操作：探索場面のプレビューチャットでボタンを押し、入力欄を見る。下書きを確認して送信する。設定画面のライブプレビューでも押す。
期待する結果：プレビューチャットでは下書きへ一度追記し、送信まで物語が進まない。設定プレビューなど入力欄のない場所では成功表示を出さない。
実際に確認した場所・日付・結果（未確認ならその旨）：PinxAI実機は未確認。
任意の補足（失敗例、対処、既知の制限、画像など）：同一表示では追記成功後にボタンを無効にする仕様。別の返答や再表示で表示状態を継ぐ用途には使わない。
