PinxAI ウィジェットサンプル投稿書式 v0.1

【概要】
サンプル名：現在地カード
何をするか：直近の本文で確定した現在地を表示する。
提供者の表示名：ウィジェット相談室
元の作品・投稿・配布ページ（公開URL、任意）：なし
対象の版（版番号・日付・固定リンクのいずれか）：0.1

【掲載・利用の希望】
索引への掲載（可／不可）：可
資料の転載・ミラー（可／不可／条件付き）：リンクによる紹介可
コードや本文の改変・再配布（可／不可／条件付き）：自分のPinxAI作品に合わせた改変・設置可。サンプル原稿の再配布は個別確認。
AIが回答時にサンプルを参照する利用（可／不可／条件付き）：可
適用するライセンス、条件、必要な表記があれば記載：上記の通り。モデルの訓練用途は対象外。

【設置】
表示する場面と位置：固定イントロの後、各AI返答の本文末尾
ウィジェット名／関数名：現在地カード／LocationCard
常時有効の設定／トリガーキーワード：空いている作品でオン／設定なし
ウィジェット以外の変更・依存する既存設定（なければ「なし」）：なし
タグで受け取る値（意味・型。初期値と欠落時の扱いも必要に応じて）：place は現在地の文字列。未確定は空文字とし、欠落・空白・型違いも画面上は「不明」。

【AI用プロンプト】
固定イントロ以外のAI返答は、本文の末尾に次の形のタグを一つだけコード枠外に出す。
<LocationCard place="広場" />
place は主人公が実際にいることが本文で確定した場所の名前。移動希望だけでは変更しない。直近までの本文を含めて現在地を確定できない場合は place=""。例の「広場」は見本とし、物語上の事実として使わない。

【プレビュー用タグ】
<LocationCard place="広場" />

【コード】
function LocationCard(props) {
  const place = typeof props.place === 'string' ? props.place.trim() : '';

  return (
    <section style={{ padding: 12, borderRadius: 8, background: '#f3f4f6', color: '#1f2937', overflowWrap: 'anywhere' }}>
      <strong>現在地</strong>
      <div>{place || '不明'}</div>
    </section>
  );
}

【再現・確認】
試す入力と操作：設定画面でプレビュー用タグを入れる。place="" と place={4} でも試す。次に、プレビューチャットで現在地を広場と確定し、移動の希望を伝えただけで未到着の返答を確認する。
期待する結果：設定プレビューは順に「広場」「不明」「不明」。プレビューチャットでは広場にいる間は表示が維持され、到着が確定してから切り替わる。
実際に確認した場所・日付・結果（未確認ならその旨）：PinxAI実機は未確認。
任意の補足（失敗例、対処、既知の制限、画像など）：他の常時有効ウィジェットがある作品では、起動方法を別途決める。
